# Discord Helper

Бот для уборки музыкальных команд и сообщений выбранных музыкальных ботов. Он срабатывает на новые сообщения через 60 секунд вне музыкальных каналов и их веток. Одна установка обслуживает один сервер Discord.

## 1. Создайте бота в Discord

1. В [Discord Developer Portal](https://discord.com/developers/applications) создайте приложение. В разделе **Bot** включите **Message Content Intent** и получите токен бота.
2. В разделе **Installation** включите **Guild Install**. В параметрах установки назначьте scope `bot` и разрешения **View Channels**, **Read Message History** и **Manage Messages**. Откройте ссылку установки и добавьте бота на свой сервер.
3. В Discord включите **Настройки пользователя → Расширенные → Режим разработчика**. Скопируйте ID сервера и музыкальных каналов через меню правой кнопки мыши. Чтобы убирать ответы музыкального бота, скопируйте его **ID пользователя** из меню профиля.

Токен храните в `.env` или в секретах хостинга. Если он попал в чат или репозиторий, сбросьте его на вкладке **Bot**.

## 2. Запустите на компьютере

Установите [Node.js 24 LTS](https://nodejs.org/en/download/). Скачайте репозиторий и откройте терминал в папке, где находится `package.json`.

**Windows PowerShell**

```powershell
Copy-Item .env.example .env
npm.cmd ci
```

**macOS или Linux**

```sh
cp .env.example .env
npm ci
```

Заполните `.env` по таблице ниже. Выполните `npm run check`, затем `npm start`. В Windows PowerShell можно использовать `npm.cmd run check` и `npm.cmd start`. Команда `check` проверяет формат полей локально. При успешном подключении `start` выведет `Discord Helper подключён`.

Отправьте `m!play тест` вне музыкального канала. В режиме `preview` совпадение появится в консоли без удаления. Когда убедитесь, что выбраны нужные каналы, поставьте `CLEANUP_MODE=delete` и перезапустите бота. Проверьте, что новое тестовое сообщение удаляется через минуту, а сообщение в музыкальном канале остаётся. Для первой проверки можно ограничить `CLEANUP_CHANNEL_IDS` одним тестовым каналом.

## Настройки

| Переменная | Значение |
| --- | --- |
| `DISCORD_TOKEN` | Токен вашего Discord-бота. Обязательно. |
| `DISCORD_GUILD_ID` | ID вашего сервера Discord. Обязательно. |
| `MUSIC_CHANNEL_IDS` | ID защищённых музыкальных каналов через запятую. Укажите хотя бы один. |
| `CLEANUP_CHANNEL_IDS` | ID каналов уборки через запятую. Пустое поле охватывает весь выбранный сервер. |
| `MUSIC_COMMANDS` | Текстовые команды через запятую. По умолчанию `m!play`. |
| `MUSIC_BOT_IDS` | ID музыкальных ботов через запятую. Удаляются все новые сообщения выбранных ботов в зоне уборки, включая публичные ответы приложений. |
| `CLEANUP_MODE` | `preview` для проверки совпадений, `delete` для удаления. По умолчанию `preview`. |
| `DELETE_DELAY_SECONDS` | Задержка от 1 до 3600 секунд. По умолчанию 60. |
| `DATABASE_PATH` | Путь к SQLite. По умолчанию `./data/cleanup.sqlite`. |

Команда должна быть первым словом сообщения. Регистр не важен. Каналы с именем `music`, в том числе с эмодзи в названии, и их ветки защищены автоматически. ID в `MUSIC_CHANNEL_IDS` сохраняет исключение после переименования канала. Закреплённые сообщения и сообщения от посторонних вебхуков пропускаются. Перед удалением бот заново проверяет сообщение и свои права. Пользовательский вызов `/`-команды другого приложения бот прочитать не может. Публичный ответ выбранного приложения обрабатывается как сообщение бота.

## Bot-Hosting.net

1. Создайте деплой **Node.js 24** или выберите более новую версию Node.js. Импортируйте репозиторий либо загрузите ZIP и распакуйте его так, чтобы `package.json`, `package-lock.json` и `src/` лежали в корне файлов. Хостинг устанавливает зависимости по `package.json`.
2. В **Окружение** добавьте настройки из таблицы. Отметьте `DISCORD_TOKEN` как секрет. Для запуска из панели достаточно переменных окружения.
3. В **Настройки → Запуск → Входной файл** укажите `src/main.js`. Переменная `STARTUP_FILE` в «Окружении» показывает значение этого поля.
4. Нажмите **Запустить** и проверьте консоль. После изменения окружения перезапустите приложение.

Встроенная SQLite создаётся при запуске. Храните `data/` на постоянном диске и сохраняйте её при обновлениях. Очередь переживает перезапуск, задания старше суток истекают. Переход в `preview` отменяет накопленные удаления. В журнале совпадений выводится ID канала, текст сообщений не записывается. Для работы достаточно исходящего соединения с Discord.

На другом хостинге с Node.js выполните `npm ci --omit=dev`, затем `npm start` из корня проекта. [Инструкция Bot-Hosting.net](https://bot-hosting.net/docs/guides/set-up-a-deployment)

## Диагностика

| Сообщение | Что проверить |
| --- | --- |
| `Exit code: 78` | Прочитайте строку выше. В ней будет имя неверного поля или подсказка Discord. |
| `Discord отклонил токен бота` | Скопируйте токен из раздела **Bot** выбранного приложения. |
| `Включите Message Content Intent` | Проверьте настройку в разделе **Bot** и перезапустите процесс. |
| `проверьте права бота` | Проверьте разрешения роли бота и переопределения в нужном канале. |
| Есть `[preview]`, сообщение осталось | Поставьте `CLEANUP_MODE=delete` и перезапустите бота, затем проверьте новое сообщение. |

Тесты правил и очереди запускаются командой `npm test`.
